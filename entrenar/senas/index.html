Versiones guardadas

    Límites

    • Para que el modelo le sirva a la comunidad, las grabaciones deben ser de personas sordas usuarias de la lengua de señas panameña. Si grabas tus propias pruebas, el modelo aprende tus gestos, no LSPan.
    • Con 3 grabaciones por seña ya entrena, pero acierta mucho más con 8 o más, de 3 personas o más. Con 3 personas, el examen se hace con alguien que el modelo no vio.
    • Reconoce señas sueltas de este vocabulario, una por una. No entiende una conversación ni señas que no le enseñaste.
    • La nota del examen se saca con grabaciones apartadas, no con las que usó para aprender.
    • Las grabaciones guardan el movimiento de las manos, no el video. Nada sale de este teléfono salvo que exportes un archivo.

    Cómo se usa

    Enseñarle señas nuevas
    1. Abre Entrenamiento y entra en «Entrenar señas».
    2. Escribe la seña y quién signa. Toca «Usar la cámara» y graba cada seña 8 veces o más.
    3. Con dos señas de tres grabaciones cada una ya puedes tocar «Entrenar ahora».
    4. Mira la nota del examen. Desde ese momento, Entender señas usa tu modelo.

    Ten en cuenta

    • Para que le sirva a la comunidad, deben grabar personas sordas que usen la lengua de señas panameña.
    • Las grabaciones guardan el movimiento de las manos, no el video. No salen del teléfono.
